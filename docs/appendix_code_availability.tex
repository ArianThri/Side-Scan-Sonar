\chapter{Code Availability and Reproducibility}
\label{app:code}

The complete implementation developed for this dissertation is available at:

\begin{center}
\url{https://github.com/ArianThri/Side-Scan-Sonar}
\end{center}

The implementation and evidence package corresponding to the reported results
is pinned at commit
\texttt{fb376d4d884142f0732bea76f024e748e8035ef3}. The repository contains the
source code, executed-configuration summaries, frozen experiment registries,
dataset split identifiers, provenance manifests, training records and
lightweight evaluation evidence.

The acquired SCTD images and annotations are not redistributed. Instructions
for placing an authorised copy of the dataset are provided in
\path{DATA.md}. Model checkpoints and generated image collections are also
excluded because of their size and dataset-redistribution considerations.

The principal implementation components are documented in
\path{CODE_MAP.md}. The complete executed pipeline is in \path{src/}; pilot
utilities and the rejected provisional splitting method are explicitly
separated under \path{archive/}.
